# Plataformas

Cada plataforma tiene su propio formulario de envío, con campos ligeramente distintos. Conocer bien la plantilla de cada una te ahorra tiempo y hace que tu reporte encaje perfecto en su flujo de triage.

* [YesWeHack](yeswehack/)
* [Secur0](secur0/)
* [Intigriti](intigriti/)

> 💡 Consejo general: independientemente del formulario específico, la estructura de contenido de [Anatomía de un buen reporte](../04-como-escribir-reportes/anatomia-de-un-buen-reporte.md) se adapta a los tres. Lo que cambia es _dónde_ colocas cada bloque de información.
